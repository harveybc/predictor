annual pooled relative MAEs on complete common DEVELOPMENT support. Select
R2 only when score_R2 < score_R0 - 1e-8; ties retain R0. Each head still
reports its own naive and remains individually eligible or ineligible.

arms produce INCOMPLETE_COMPARISON, never an R0-only scientific selection.

branches, optimizer and fine-tune stopping. Only R2 imports branch weights.

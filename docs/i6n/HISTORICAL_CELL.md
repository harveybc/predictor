## Clock Contract

The manifest is an explicit caller attestation, not evidence generated by this
adapter. Exact required fields (no extras):

```json
{
  "schema": "i6n.source_clock.v1",
  "status": "RESOLVED",
  "coverage_mode": "complete",
  "data_kind": "historical",
  "input_sha256": "<NPZ SHA256>",
  "features": ["<the same ordered 20 feature names>"],
  "calendar_sha256": "<canonical SHA256 of the entire config.calendar object>",
  "timestamp_semantics": "UTC_BAR_END",
  "availability_policy": "AT_TIMESTAMP",
  "clock_policy": "<resolved conversion policy, evidence reference and scope>"
}
```

Compute `calendar_sha256` with
`tools.i6n_contracts.eligibility.canonical_digest(config["calendar"])`.
File SHA256 is over exact bytes, not decoded arrays. `AT_TIMESTAMP` attests
that the price and every finite selected feature in a row were available at
that row's UTC bar-end `ts`. This adapter does not support late feature
revisions; prepare a causally valid NPZ or refuse. Missing feature values may
be nonfinite and carry independent source masks. The NPZ contains `ts` (unique,
increasing, signed integer UTC seconds, whole hours, all pre-2025), numeric
`x` of shape `(N,20)`, and finite strictly positive `price` of shape `(N,)`.

An unresolved clock is refused BEFORE NPZ decoding or TensorFlow import. No
timezone is guessed, no retained timestamp is relabelled, and no synthetic
coverage escape exists. A token, a successful download, or matching a bounded
2024 sample does not by itself resolve all four years or prove causal feature
availability. The parent owns clock resolution, evidence custody and the
truth of the manifest. Unkeyed hashes detect inconsistent bytes, not forgery.

## Temporal And Resource Rules

The independent full hourly calendar grid enters `build_weekly_partitions`.
Missing current bars exclude input eligibility but never erase origin audit
rows. History is exactly four calendar years; the last 28 elapsed days form
inner validation. TRAIN targets are purged at inner start; inner labels must
be available by the prior market-close refit cutoff. TEST starts at 2025 UTC.
Input context needs actual retained history at least `(samples-1)*spacing`
hours before history start. Windows include current `t`, use exact elapsed
hours, retain market gaps and interleaved feature/source masks, and never
compress missing hours into observed-bar offsets.

Feature imputation/scaling uses only eligible TRAIN origin rows, through
`i6e_compact_run.scaled_inputs`. Each head's log-return center and standard
deviation use only eligible TRAIN labels; degenerate target scales fail.
Here there is exactly one head. No inner/evaluation values fit either scale.
Fully excluded rows remain in partition digests/counts but are not materialized
for fitting. Each window construction is at most `training.batch_size` rows.
The existing `fit_masked` API needs admitted full TRAIN/inner arrays: this is
bounded materialization, NOT streaming training or memmap-based optimization.

Resource checks bound compressed/uncompressed input bytes, source/grid rows,
sample count, total materialized array bytes, window-batch bytes, worst-case
optimizer updates and model parameter count. These byte counts are NOT a
TensorFlow peak-RSS or GPU workspace prediction. External memory admission
is mandatory; size it on the intended host. The wall budget is enforced by
the run timer and checked on progress. No cheaper automatic retry is allowed.

## Artifacts And Verification

`STATUS.json` is atomically replaced on each update/epoch, with elapsed time
and an epoch-derived remaining-time estimate after the first completed epoch.
C1 evaluation support is sealed before fitting, using the actual wall time,
not a backdated prospective receipt. The reloaded checkpoint must reproduce
selected weights and predictions. C2 original-price model and naive scores
use exactly the same C1 per-head M. No U receipts or trading utility are invented.

Completion retains `RESULT.json`, `model.keras`, `calendar_input.json`,
`metric_input.json`, and the pre-fit `population.json`. Reuse requires full
config/code/runtime/input/manifest identity, every artifact digest and a fresh
C2 rescore. Changed identity, damaged artifacts, failed/interrupted output or
orphan artifacts refuse without fitting. Use a new directory only after an
explicit operator decision; neither status nor rerun silently recovers a fit.
Status reads do not import TensorFlow or decode NPZ arrays. An unlocked
retained RUNNING state is reported as INTERRUPTED without altering its bytes.
CLI exit codes are 0 for verified completion, 3 for no status, 4 for a retained
non-complete state, and 2 for refusal/damage. Execution exceptions persist
FAILED and propagate; SIGKILL cannot record failure but cannot trigger a retry.
Timer interrupts are delivered by Python; external admission is still needed
to kill a native operation that does not return promptly to Python.

# Referencias de la propuesta L2/RL

Los números del nombre coinciden con `[n]` en

`docs/propuesta_doctoral_seleccion_multifidelidad_rl.pdf`

(bibliografía IEEE, orden de primera cita). Abrir el PDF de la propuesta y el archivo `NN_…pdf` a la vez.

Los PDF quedan **locales**. No se suben al remoto: varios son copias de autor o de archivo, y [22] es un escaneo JSTOR.

Ninguno de los 22 es un libro. Donde el artículo de revista está de pago se dejó el preprint o el informe técnico abierto, y se marca abajo.
